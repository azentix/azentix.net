Frequently asked questions

Short answers. The guide has the details.

General

Is MacTune free?

Yes. It's open source under the MIT license, with no ads, subscriptions or in-app purchases.

Which Macs are supported?

macOS 15 Sequoia or later.

Where do I get it?

Signed downloads are coming soon. Write to contact@azentix.net and we'll let you know when it's ready. Developers can build it from source, see Install.

Does it run in the background?

Only while it's open or in the menu bar. Nothing is cleaned or removed automatically. The network filter is a separate system extension that applies your rules even while the window is closed.

Does it slow my Mac down?

No. When idle it uses a few percent of one CPU core, and hidden sections stop updating. Animations follow Reduce Motion.

Cleaning

Is it safe to delete caches?

Yes, apps rebuild their caches when they need them. Apple's own caches are skipped, and you review every item before anything is deleted.

Can I undo an uninstall?

Yes. The app and its files go to the Trash; drag them back to restore. Only cache cleaning and emptying the Trash are permanent.

Why does it find less than I expected?

Some folders need Full Disk Access. Add MacTune in System Settings → Privacy & Security → Full Disk Access.

Why didn't the cleaner rescan?

A scan is kept for an hour so the cleaner opens instantly. Press Rescan for fresh numbers.

Network

Does blocking an app close it?

Never. The network filter stops its traffic; the app keeps running and reconnects when you allow it again.

Does MacTune read my traffic?

No. The filter only looks at which app opened a connection to decide allow or drop. Content isn't inspected, logged or sent anywhere.

I set a limit and it said "limit reached" right away

The app had already used more than that today. Choose "Start counting from now", or add +10 MB / +100 MB / +1 GB for today.

Will it block system updates or iCloud?

No. System services and command line tools always keep their network.

Does it work with a VPN?

Usually yes. If you also run another firewall, such as LuLu, a connection blocked by either one stays blocked.
