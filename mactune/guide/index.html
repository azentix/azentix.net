MacTune guide

Everything each section does, what it touches, and how to undo it.

Install

  1. Move Azentix MacTune.app to /Applications. The network filter only loads from there.
  2. Open it. macOS 15 Sequoia or later is required.
  3. For internet switches and limits, open Network → Install and allow the extension in System Settings → General → Login Items & Extensions → Network Extensions. See Network setup.
  4. Allow notifications when asked, so you hear when an app reaches its limit.

Build from source

MacTune is plain SwiftPM with no dependencies:

./scripts/bundle.sh
open "build/Azentix MacTune.app"

The signed build with the network filter needs an Apple developer team and XcodeGen: set your team in project.yml, then run ./scripts/build-signed.sh.

Full Disk Access

macOS protects some folders, such as other apps' containers. MacTune works without access, it just finds less. To scan everything, add the app in System Settings → Privacy & Security → Full Disk Access. The Cache Cleaner shows a banner with a shortcut when it hits a protected folder.

Smart Scan

The start screen. Rings show disk, memory (the same "Memory Used" as Activity Monitor) and CPU load. Press Scan to measure junk in every cleaner category, then Clean Now, or Review to pick items first. Below are the apps using the most memory and shortcuts into the other sections.

Cache Cleaner

Xcode JunkDerivedData, old iOS DeviceSupport, simulator caches

Expand a category to tick individual folders. A scan is reused for an hour, so switching sections doesn't rescan your disk; press Rescan any time for fresh numbers.

Cache cleaning deletes permanently, after a confirmation. Caches are rebuilt by their apps, so the first launch afterwards can be a little slower.

Uninstaller

Lists apps in /Applications and ~/Applications. Pick one, or drop an .app on the window, to see its related files: Application Support, Caches, Preferences, Containers, Group Containers, Saved State, Logs and Launch Agents/Daemons.

  • Files matched by bundle ID are ticked. Weaker name-only matches are flagged and left unticked.
  • The magnifier shows a file in Finder.
  • Uninstall moves the app and the ticked files to the Trash. If the app is running, it's asked to quit first.
  • Apple apps are protected. Apps owned by root use the standard administrator prompt.

Large & Old Files

Scans Downloads, Documents, Desktop, Movies, Music and Pictures. Filter by size (over 10 MB to over 1 GB) and age (over a month to over a year), or by name. Tick files and choose Move to Trash.

Running Apps

Apps shows your apps with memory use; All Processes adds background processes, CPU and owner. Select one or many and choose Quit or Force Quit. MacTune refuses to stop PID 1, other users' processes and critical macOS processes such as Finder, Dock and WindowServer.

Limited Launcher

A focus mode: while it's on, only the apps you allow can run. Turning it on lists the other open apps and asks them to quit after you confirm; apps opened later are closed right away. Finder, Dock, System Settings, menu bar helpers and background services are never touched. Toggle it in Running Apps or the menu bar.

Limited Launcher is about which apps run. To keep an app running but offline, use the Network switches instead — they never close anything.

Startup Items

Launch agents and daemons from ~/Library/LaunchAgents, /Library/LaunchAgents and /Library/LaunchDaemons. Disabling is persistent (launchctl disable) and reversible; Remove moves the plist to the Trash. System-wide items ask for the administrator password.

Login items added through System Settings (SMAppService) can't be listed without root yet; manage them in System Settings → General → Login Items.

Menu bar

Choose what the menu bar shows: CPU, memory, network speed, free disk and Hotspot Guard state. The panel has live rings, Hotspot Guard and Limited Launcher switches, current network speed, quick scan and clean, top memory apps with a quick quit button, Empty Trash, and shortcuts into the app.
