Network & Hotspot Guard

See which apps use your internet, switch any of them off, give them a daily budget, and protect your iPhone's data when you're tethered.

Overview

The Network section shows live download and upload per app, a live chart, the last 14 days, and how much each app used today. Helpers count as their app: Chrome's renderer processes are added to Google Chrome. The Today, Now and Name buttons sort the list.

Each app has one Limit & access cell. A progress bar there means it has a limit; a crossed-out Wi-Fi icon means its internet is off; a green shield means it's allowed during Hotspot Guard.

Setup

Cutting traffic needs the MacTune network filter, a Network Extension that macOS runs separately from the app.

  1. Make sure the app is in /Applications.
  2. Open Network and press Install on the banner.
  3. Allow it in System Settings → General → Login Items & Extensions → Network Extensions, and accept the "filter network content" prompt.

The banner disappears once the filter is running. Without it, MacTune still measures traffic and sends limit notifications, but it can't stop anything — and it never closes apps as a substitute.

Internet switch

Turn Internet access off and the app goes offline immediately, including connections it already had open. The app keeps running: a browser shows its "no connection" page, a chat app shows that it's reconnecting. Turn it back on and it reconnects by itself.

Daily limits

Press Set limit and pick an amount per day. Today's traffic counts towards it; if the app already used more than the new limit, choose Start counting from now instead.

  • At 80% you get a notification "App is close to its daily limit" with how much is left.
  • At 100%: "App reached its daily limit" and its internet is paused until midnight.
  • +10 MB / +100 MB / +1 GB add extra for today only. Tomorrow the normal limit applies again.
  • Change limit… edits the amount, Remove deletes it.

Traffic to the Mac itself (127.0.0.1, ::1, e.g. the Android emulator or a local dev server) is not counted.

Hotspot Guard

One switch for metered connections. While it's on, only the apps you allowed can use the internet. Everything else keeps running, offline.

  • Allowed Apps… opens one list with a switch per app: apps seen on the network today, apps running now and apps you already allowed.
  • Auto on iPhone hotspot turns the guard on by itself on Personal Hotspot and Low Data Mode networks, and off again when you leave them.
  • Apps started by an allowed app inherit its access, so an allowed IDE can still run its build tools.
  • The bar and the menu bar show how much was used since the guard was turned on.

You can also flip the guard from the menu bar panel.

Ask for new apps

Connection alerts, like LuLu. Turn on Ask for new apps in Network and the first time an app connects to the internet, the connection waits while a small alert shows the app and where it's connecting.

  • Allow lets the app through from now on. Deny turns its internet off, the same as the Internet switch.
  • Rules… lists every answer. Switch one between Allow and Deny, or forget it to be asked again.
  • Apps you already used before turning it on count as known and aren't asked about. Apple's own apps and system services never are.
  • If nobody answers within a minute, or MacTune isn't running, the connection goes through, so nothing hangs.

System services (DNS, software update, iCloud daemons), command line tools, Finder, Dock and MacTune itself are never blocked.

How it works

Traffic numbers come from macOS's own nettop. Blocking is done by an NEFilterDataProvider system extension. For every network flow it finds the app responsible (helpers and XPC services map to their parent app), checks the current rules, and allows or drops the flow. Rules travel from the app to the filter through the system's filter configuration; no traffic content is inspected or stored.

Troubleshooting

The banner says "Network filter isn't running"

Press Install or Turn On, then check System Settings → General → Login Items & Extensions → Network Extensions. The app must be in /Applications.

I don't get limit notifications

Allow notifications for Azentix MacTune in System Settings → Notifications. The Network section shows a banner with a shortcut when they're off.

An app still loads while it's blocked

Some apps show cached content. New requests fail; reload to check.

How do I remove the filter?

Delete the app (MacTune's own Uninstaller works), or turn the extension off in System Settings → General → Login Items & Extensions.
